# Evidence index

- `baseline-checks.md`: commands and results before `baseline-demo`.
- `baseline.json`: diagnosis generated before queue implementation; source identity is in `docs/02-diagnosis.md`.
- `comparison.json`: fresh-seed batch and outage/retry/replay measurements from `scripts/benchmark.py`.
- `verification.json`: actual final commands, exits, output, source commit and platform from `scripts/verify.py`.
- `backend-tests.xml`: final pytest JUnit report.
- `unexpected-errors-red.txt`: actual failing regression before the unexpected-adapter-error implementation fix; see `docs/06-unexpected-adapter-errors.md` for root cause and recovery.
- `ui-results.json`: Playwright report; the baseline tag preserves the initial one-test report, while this checkout has the expanded suite.
- `baseline.png`, `improved.png`, `failed-delivery.png`, `mobile.png`: actual browser screenshots of synthetic live state, generated by UI tests and visually inspected.

These are reproducible artifacts, not dashboard placeholders. Regeneration changes timestamps and test durations. Correctness/action measurements are deterministic; machine timings are not reported as human effort saved. UI tests pause the worker for stable checkpoints; backend tests separately verify automatic delivery.
